# Iris

Фоновая утилита заботы о глазах для Windows и macOS.

Каждые N минут Iris перекрывает рабочий стол спокойной картинкой и короткой памяткой: посмотреть вдаль, моргнуть, прикрыть глаза. Через заданные секунды экран снова освобождается. Программа живёт в системном трее.

## Запуск из исходников

Нужны Node.js 20+ и npm.

```bash
npm install
npm start
```

При первом запуске откроется окно настроек. Дальше Iris остаётся в трее.

## Сборка

```bash
npm run build:win
npm run build:mac
```

Готовые файлы появятся в `dist/`. На Windows — portable `.exe`. На macOS — zip с `Iris.app` для Apple Silicon и Intel. Сборку подписи и `.dmg` лучше делать на Mac.

## Настройки

- **Интервал работы** — через сколько минут показать паузу (по умолчанию 20).
- **Длительность паузы** — на сколько секунд закрыть экран (по умолчанию 30).
- **Запускать с системой** — стартовать скрыто после входа в аккаунт.
- **Можно пропустить** — кнопка «Пропустить» и клавиша Escape.
- **Звук** — тихий сигнал в начале паузы.

Из трея можно открыть настройки, поставить таймер на паузу или начать отдых сразу.
